Notes
-----
6play    No show carries an api_id in programs.json, so every program ID above
         was resolved live through the programs API (name match, then Algolia).
mytf1    TF1 has no per-show metadata endpoint: the show is matched by name
         inside this channel-filtered programs list. If it is absent, the
         provider retries the same URL without the channel filter.
cbc      No separate metadata call — this show endpoint returns metadata and
         the full season lineup together.

Notes
-----
         programs.json holds only provider/slug/name; description, channel,
         genres, year, rating and artwork all come from the endpoints above.
6play    No show carries an api_id in programs.json, so every program ID above
         was resolved live through the programs API (name match, then Algolia).
francetv A show is addressed as <channel>_<slug>; the channels are probed in
         order and the answer cached.
mytf1    TF1 has no per-show metadata endpoint: the show is matched inside the
         programs list, whose channel filter is the only filter the query
         accepts. The unfiltered page is tried first, then tf1, tmc, tfx and
         tf1-series-films.
         Episodes: https://www.tf1.fr/graphql/web?id=a6f9cf0e&variables=
         {"programSlug":"<tf1-slug>","offset":0,"limit":50,...}
cbc      No separate metadata call — this show endpoint returns metadata and
         the full season lineup together. Year and rating are read off the
         episodes it already carries.
